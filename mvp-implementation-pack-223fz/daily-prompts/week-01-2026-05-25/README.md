# Daily prompts: Week 01, 2026-05-25 to 2026-05-29

Эта папка содержит готовые ежедневные задачи-промпты для первой недели реализации MVP. Неделя соответствует `sprints/sprint-01-skeleton.md`: skeleton продукта и read-only loop.

## Как использовать каждый день

1. Утром откройте файл дня.
2. Скопируйте блок `Implementation prompt` в нейро-агента, который пишет код.
3. После результата скопируйте блок `QA prompt` в отдельного агента-ревьюера.
4. Исправления отдавайте первому агенту маленькими patch-задачами.
5. Вечером заполните `Daily result log` и сохраните в `docs/progress/YYYY-MM-DD.md` будущего репозитория.

## Важно про экономию токенов

Daily prompt уже содержит нужный статичный контекст. Не просите агента заново читать `deep-research-report.md`, sprint-файлы и весь `mvp-implementation-pack-223fz`. Агент должен читать только фактический код репозитория, который он меняет или проверяет.

Статичные документы открываются только если prompt неполный, есть противоречие или вы явно просите сверку.

## Правило фиксации

Каждый день должен закончиться одним статусом:

- `DONE`: задача работает, проверки запущены, результат записан.
- `PARTIAL`: часть работает, известен список недоделок.
- `BLOCKED`: есть конкретный блокер и следующий шаг.
